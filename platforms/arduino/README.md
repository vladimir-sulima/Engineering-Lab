# Arduino Platform

This area contains Arduino-specific lessons, projects, and reusable libraries.

- [`lessons/`](lessons/) — Learning artefacts, each focused on one main question.
- [`projects/`](projects/) — Devices and experiments that apply one or more lessons.
- [`libraries/`](libraries/) — Reusable code created by the lab.

Use the repository [standards](../../docs/ENGINEERING_STANDARDS.md) and [templates](../../templates/) when adding work.
