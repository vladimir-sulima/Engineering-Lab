# Engineering Lab

A long-term, family-friendly engineering lab for learning embedded systems by building understandable, documented devices.

**Founded:** 2026-07-23  
**Status:** Active  
**Current platform:** Arduino Uno

> Understand first. Build second. Optimize third.

## What belongs here

- Lessons that teach one clear engineering idea.
- Reproducible projects with code, wiring, parts, and notes.
- A living inventory of the workshop and a practical wishlist.

## Repository map

| Location | Purpose |
| --- | --- |
| [`docs/`](docs/) | Lab standards, roadmap, inventory, wishlist, and history. |
| [`platforms/arduino/`](platforms/arduino/) | Arduino lessons, projects, and reusable libraries. |
| [`templates/`](templates/) | Starting points for new lessons and projects. |
| [`shared/`](shared/) | Cross-project datasheets, diagrams, and images. |
| [`scripts/`](scripts/) | Small automation tools, added only when genuinely useful. |

## Getting started

1. Read the [engineering standards](docs/ENGINEERING_STANDARDS.md).
2. Check the [roadmap](docs/ROADMAP.md) and [inventory template](docs/INVENTORY.template.md).
3. Optionally copy [`docs/INVENTORY.template.md`](docs/INVENTORY.template.md) to `local/INVENTORY.md` to keep a private equipment record.
4. Begin the next planned lesson when the Arduino setup is ready.
