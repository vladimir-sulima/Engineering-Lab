# Workshop Inventory — Template

Use this template for a private local inventory. Do not commit personal equipment, quantities, order status, or other information you would not want to publish.

## How to use

1. Copy this file to `local/INVENTORY.md`.
2. Fill in the local copy as equipment arrives or changes.
3. Keep `local/` untracked; it is excluded by `.gitignore`.

## Inventory rules

- Record enough detail to decide whether a lesson or project can be built.
- Do not label ordinary consumables individually.
- Label otherwise indistinguishable duplicates only when it prevents confusion.
- Use statuses such as `Available`, `Ordered`, `Planned`, and `To verify`.
