## Arduino Uno learning path

### 1. Digital foundations

- [ ] `L-001 • First Blink` — What is a microcontroller and how do we upload a sketch?
- [ ] `L-002 • External LED` — What is a digital output and why does an LED need a resistor?
- [ ] `L-003 • Button Input` — How does a microcontroller read a switch reliably?
- [ ] `P-001 • Traffic Light` — Apply digital inputs and outputs in a small device.

### 2. Analog input and timing

- [ ] Potentiometer and `analogRead()`.
- [ ] PWM brightness control.
- [ ] Timing without blocking with `millis()`.
- [ ] Electronic dice or reaction game.

### 3. Sensors and actuators

- [ ] Buzzer and simple feedback.
- [ ] Servo motor control.
- [ ] Distance or light sensor.
- [ ] Parking sensor or automatic night light.

### 4. Real devices

- [ ] Display and I²C communication.
- [ ] Real-time clock and persistent settings.
- [ ] A documented device for the home, workshop, or garden.

### 5. Next platforms

ESP32, Raspberry Pi Pico, and other platforms will be added only when a real project needs them.
